# SP Networking Guide — Website Example

This repository contains the first example of a GitBook-inspired networking documentation website.

## Preview locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the default branch and the **/(root)** folder, then save.
5. Wait for GitHub Pages to publish the site. The published URL will appear in Settings → Pages.

## Included in this example

- Responsive documentation layout with sidebar navigation
- Search/filter for topics
- Light/dark theme toggle
- Copy buttons for CLI examples
- Article sections, tables, callouts, and previous/next navigation

## Content note

The networking articles in this first version are demonstration content only. Replace or revise them using the material supplied by the repository owner before treating the site as a finished study guide.
